FAQ

What's the difference between the no-signup free tier and the email-signup free tier?

Same APIs, different rate limits. No-signup is 100 calls/day per IP. Email signup is 1,000 calls/day per key (and you can use the same key from multiple IPs / servers). Hobby raises that to 5,000/day for $9.99/mo. The no-signup tier exists because "try before you buy" shouldn't require a card or an email.

Do you charge overage fees?

No. If you hit the daily limit, the API returns HTTP 429 with a clear message. We won't surprise-charge you. Upgrade from the dashboard if you need more.

Can I switch plans?

Yes, instantly. Upgrade takes effect immediately; downgrade takes effect at the end of the current billing period. Paddle handles the proration.

Do you offer annual billing?

Not yet. We're keeping pricing simple while we learn what people actually need. If you want a 10% discount for annual, write to billing@sitetrace.it.com.
