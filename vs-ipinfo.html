Where sitetrace wins

Reputation, not just geo

IPinfo is great at "where is this IP from". We're great at "is this IP on any spam blocklists". Different questions, different APIs. If you care about blocking fake signups, our score (built from 7 DNSBLs) is more directly useful than IPinfo's privacy flag.

Price for small projects

Our free tier (1,000/day with email) is enough for most side projects. IPinfo's free tier is 50k/mo which sounds bigger, but it's a no-card-required trial that requires a credit card for the paid plans and is structured for "real" customers. For a hobby project, ours is friendlier.

Edge cache, edge compute

We run in 300+ Cloudflare POPs. IPinfo is in AWS regions. The first request from a new region is slow either way; subsequent requests are usually faster on our end.

Where IPinfo wins

Data depth

IPinfo has 8+ years of curated IP data, ASN databases, carrier detection, company names, and CIDR ranges you can download. Our geo comes from ip-api.com, which is good but not as deep as IPinfo's own data.

Privacy/VPN/TOR detection

IPinfo's privacy detection is the industry standard. We flag "proxy" from ip-api.com; IPinfo has a much richer taxonomy (VPN, TOR, relay, public proxy, mobile proxy, etc.).

Downloadable databases

If you want to ship a self-hosted version (air-gapped, no API call), IPinfo sells you a one-time license for the database. We don't.

Tenure + customer base

IPinfo is used by big companies. We're new. If "who else uses this" matters for your procurement process, IPinfo is the safer pick.

Which should you use

Use sitetrace if…

You want DNSBL-based reputation scoring, a generous free tier for small projects, or you're on the Cloudflare edge stack.

Use IPinfo if…

You need the deepest possible IP data, accurate privacy/VPN detection, downloadable databases, or a vendor with a long track record.

Use both

Nothing wrong with this. Use IPinfo for the "where is this IP" enrichment, and us for the "should I let this IP sign up" decision.
