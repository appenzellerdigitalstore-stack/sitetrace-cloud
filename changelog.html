v0.1.0 — launch

Initial release. Six APIs live:

  • /api/shot — Screenshot (Cloudflare Browser Rendering)
  • /api/ip — IP reputation (7 DNSBLs + geo)
  • /api/email — Email deliverability (SPF/DKIM/DMARC/MX/BIMI)
  • /api/headers — HTTP security-header score
  • /api/preview — Open Graph / URL preview
  • /api/certs — SSL / Certificate Transparency

Pricing: free 100/day (no signup) / 1,000/day (email signup), Hobby $9.99/mo, Pro $30/mo.
